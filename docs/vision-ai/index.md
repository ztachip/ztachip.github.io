# Vision & AI

ztachip is designed to accelerate both neural-network inference and the image
processing that commonly surrounds it.

Supported project examples include:

- image classification;
- SSD/MobileNet object detection;
- Canny edge detection;
- Harris corner detection;
- optical flow and motion processing;
- image resizing and color conversion;
- contrast/equalization and filtering;
- transformer/LLM inference.

This breadth is important at the edge, where a useful application often needs
camera preprocessing, AI inference, control logic, and post-processing in the
same low-power device.
