# Getting Started

This section takes a new developer from a clean Ubuntu installation to a
running ztachip application.

## Prerequisites

You will need:

- an Ubuntu development environment;
- the RISC-V GNU toolchain;
- the ztachip source tree;
- Xilinx Vivado when building the Arty A7 FPGA image;
- OpenOCD and GDB for JTAG loading/debug;
- optionally MicroPython, which is the recommended high-level environment.

The reference hardware uses the Digilent Arty A7 platform together with a VGA
Pmod and camera module for vision demonstrations.
